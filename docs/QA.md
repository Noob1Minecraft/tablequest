Проверка `data-design="after-hours"` подтверждает новый интерфейс. Скриншоты доступны в артефакте `public-browser-review` соответствующего Actions run в течение 7 дней. Окончательный статус каждого деплоя следует смотреть в GitHub Actions.

## Что остаётся проверить человеком

- Читаемость с расстояния за реальным столом и фактическое время входа 15–20 секунд с четырьмя гостями. Стандартный путь содержит три основных нажатия до первого задания, но это не заменяет usability-тест.
- Казахская редактура с носителем языка; понятность и одинаковая сложность заданий для реальных команд.
- Сканирование напечатанного QR при ресторанном освещении.
- Реальные награды только после согласования с рестораном. Текущая награда явно обозначена как demo.
