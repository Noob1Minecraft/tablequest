## Visual direction

**After Hours:** камерный ресторан вечером, тёплый свет, спокойствие и живой разговор. Сохраняется TableQuest, но исчезают пастельная игровая иллюстрация, emoji-карточки и технические баннеры. Ключевой визуальный мотив — тонкое кольцо сервировки / приглашение за общий стол.

## Design system (src/styles.css)

- Background `#111310`; elevated `#191c18`; card `#20241e`.
- Champagne accent `#ddc396`; off-white text `#f3efe5`; secondary `#b6b8ab`.
- Success / Team B `#a8b9a2`; Team A `#ddc396`; destructive `#e8afa0`.
- Display: Georgia/Times serif; UI: system sans, Segoe UI/Arial. Системные шрифты поддерживают RU/KK/EN, не требуют загрузок и работают офлайн.
- Display 38–78px, title 30–48px, quest prompt 28–44px, body 16px, caption 12px, controls 14px.
- Spacing: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 px.
- Radii: 8 / 16 / 24 px; full radius только для небольших меток и круглых элементов.
- Shadows: только для elevated surfaces, без стекла и неона.
- Primary: champagne + charcoal; secondary: border; ghost: text; destructive: muted terracotta.
- Selected: accent border + checkmark; disabled: subdued surface and explicit description. Состояние не передаётся только цветом.
- Motion: 180–260ms entrance/score; 6s subtle breathing. Все анимации отключаются через prefers-reduced-motion.

## UX decisions

Welcome → context (тип, число, время) → mode → quest. Названия команд — необязательная раскрываемая настройка на экране режима, без дополнительного шага. Старый screen=teams сохранён для восстановления старых игр.

Число участников: 2 / 3 / 4 / 5 / 6+. Выбор 6+ показывает компактное уточнение 6–8, чтобы не потерять существующий диапазон и честное распределение команд.

Главный текст задания отделён от инструкции. Phone Down не переключается автоматически после таймера. Pause вторичен. Recap показывает режим, название компании, фактические результаты и явно демонстрационную награду. «Ещё один Quest» сохраняет настройки; «Другой режим» возвращает к режимам; «Завершить» ведёт к короткому отзыву.

QR находится во вторичном меню. Статус PWA/обновления также там; гостевые экраны не показывают технических баннеров. Сообщение о невозможности сохранить прогресс остаётся понятным предупреждением без терминов реализации.

`?demo=true`: 4 друга, Fun, 5 минут, 3 заранее выбранных раунда. `?demo=true&mode=battle`: мгновенный Team Battle. Демо имеет отдельное локальное сохранение, не затирает обычную игру. Ручное завершение раунда позволяет провести короткий pitch без поддельного таймера.

## Проверка текстов заданий

Сохраняются все 18 id и фильтры. У каждого задания появляются короткий крупный prompt и отдельная инструкция на трёх языках. Все 18 формулировок сокращаются. В b3 и b4 команды решают симметричные задачи: сами выбирают разные задания одинакового типа для соперника; одинаковое время и правила. Никаких прикосновений к посуде, перемещений, алкоголя, личных признаний или унизительных условий.
