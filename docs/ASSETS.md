# Изображения и иконки

`public/dining-evening.webp` и `public/dining-evening-small.webp` — оригинальное изображение, сгенерированное для этого проекта инструментом OpenAI imagegen: вечерний ресторанный стол, свеча, стекло и светлая керамика, без людей и чужих логотипов. Исходный PNG преобразован в WebP шириной 1440 и 720 px, примерно 56 и 20 KiB. На мобильном загружается меньшая версия через picture/source.

Изображения Behance не скачивались и не включались в приложение. Ссылки используются только для описания визуальных референсов в DESIGN.md.

Favicon и PWA-иконки — собственная композиция TableQuest с монограммой и кольцом. UI-иконки — установленный ранее lucide-react. Используются системные шрифты; сетевых запросов к библиотекам шрифтов нет. Новых runtime-зависимостей для редизайна не добавлено.
