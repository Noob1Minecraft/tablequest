# TableQuest

**Технологии, которые возвращают нас друг к другу.**

[Открыть сайт](https://noob1minecraft.github.io/tablequest/) · [GitHub](https://github.com/Noob1Minecraft/tablequest)

TableQuest — мобильное веб-приложение/PWA для живого общения в кафе: один QR-код, один телефон на компанию, короткие задания и время вместе. Без аккаунтов, API-ключей и backend.

Дизайн **After Hours**: угольные поверхности, тёплый свет, акценты шампань и спокойная типографика. [Референсы и дизайн-система](docs/DESIGN.md) · [Проверки и ограничения](docs/QA.md).

Для презентации: [Fun demo](https://noob1minecraft.github.io/tablequest/?demo=true) · [Team Battle demo](https://noob1minecraft.github.io/tablequest/?demo=true&mode=battle). Сразу открывается первое задание: 4 друга, 5 минут, 3 раунда. Демо сохраняется отдельно от обычной игры.

## Запуск

Нужен Node.js 22.12+ (рекомендуется Node.js 24 LTS).

```sh
npm install
npm run dev
```

Откройте http://localhost:5173. Для телефона в той же Wi-Fi сети используйте Network URL, который выводит Vite. PWA требует HTTPS или localhost; на обычном HTTP по локальной сети сервис-воркер не устанавливается.

```sh
npm run build       # TypeScript + production-сборка в dist/
npm run preview     # http://localhost:4173, в том числе проверка PWA
npm test            # логика выбора, счёт, восстановление, переводы
npm run test:e2e    # браузерные сценарии, offline, адаптивность, QR
```

E2E локально использует установленный Microsoft Edge; в CI — Chromium (`npx playwright install chromium`). Перед локальным E2E нужна `npm run build`. Переменная `PLAYWRIGHT_BASE_URL` позволяет проверить уже опубликованный сайт вместо локального preview. Workflow автоматически проверяет публичный GitHub Pages после деплоя и сохраняет скриншоты на 7 дней.

### Если npm в Windows не запускается

При ошибке `Cannot find module ... AppData/Roaming/npm/.../npm-cli.js` можно использовать исправную копию npm из установленного Node.js, не меняя настройки компьютера:

```powershell
function npm { & 'C:\Program Files\nodejs\node.exe' 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' @args }
npm install
npm run dev
```

Функция действует только в текущем окне PowerShell. В ограниченном окружении задайте доступный кеш: `npm install --cache .tools/npm-cache`.

## Возможности

- RU / Қазақша / English: весь интерфейс, 18 заданий (по 6 на режим), ошибки, результаты и обратная связь.
- Определение первого поддерживаемого языка браузера и сохранение ручного выбора. Язык переключается без сброса игры.
- Компания: друзья, пара, семья или праздник; 2–8 участников; 5 или 10 минут (примерная длительность).
- Connect — вопросы и истории; Fun — импровизация и юмор; Team Battle — соревнование двух команд от 4 участников.
- 3 или 5 неповторяющихся заданий в сессии; текущий набор подобран по режиму, категории и размеру компании. Базовый каталог подходит всем категориям (`any`); схему можно расширять специализированными заданиями.
- Именованные команды, разделение поровну, 1 очко победителю или по 1 за ничью, итоговый счёт.
- Welcome → компания → режим → задание: три основных нажатия с настройками по умолчанию. Названия команд редактируются прямо на экране режима, без обязательного дополнительного шага.
- Крупный вопрос и отдельная короткая инструкция. Спокойный экран «телефон вниз», карточка воспоминания в recap, повтор игры или смена режима с сохранением компании.
- Таймер 60/90 секунд, пауза, досрочное завершение. Сохранённый deadline учитывает сворачивание и перезагрузку страницы. После истечения времени переход выполняется по кнопке, чтобы не оборвать разговор.
- Восстановление незавершённой игры через «Продолжить игру». Валидация повреждённых сохранений, работа без доступного localStorage с уведомлением.
- Recap пройденных заданий, фактическое время с момента начала (включая паузы, минимум 1 минута), демо-награда «Легенды этого стола».
- Отзывы хранятся только на устройстве (до 50). Они **не отправляются** в ресторан или владельцу сайта.
- Устанавливаемая PWA: манифест, PNG-иконки, версионированный precache Workbox, уведомление об обновлении. Обновление не применяется автоматически посреди раунда.
- Полный игровой сценарий и три языка работают без интернета после первого успешного кеширования production-версии. При первом визите без сети загрузка невозможна.
- Генератор скачиваемого SVG QR-кода для публичной HTTPS-ссылки. Параметр `?table=12` показывает номер стола на стартовом экране.
- Адаптивность 320px–desktop, клавиатура, подписи кнопок, фокус при смене экранов, уменьшение анимации по настройке ОС.

Награда демонстрационная: реальные скидки и подарки ресторана не обещаются. Пользовательские названия команд не переводятся автоматически. Все данные и переводы входят в сборку; внешних шрифтов, аналитики и сетевого переводчика нет.

## Технологии и структура

React 19, Vite 8, TypeScript, CSS, Lucide, QRCode, vite-plugin-pwa/Workbox. Vitest и Playwright для проверок.

```text
src/
  App.tsx               # экраны и игровой сценарий
  game.ts               # выбор заданий, счёт, таймер, хранение
  session.ts            # создание обычной / демонстрационной сессии
  types.ts              # типы предметной области
  i18n/index.ts         # типизированные словари RU/KK/EN
  data/quests.json      # локальный переводимый каталог
  components/Modal.tsx   # доступные диалоги и генератор QR
  components/Welcome.tsx # ресторанный стартовый экран
  components/Teams.tsx   # команды и табло
  styles.css            # адаптивный дизайн
public/                 # иконки PWA, favicon, два размера WebP hero
docs/                   # дизайн, происхождение изображения, QA
tests/                  # логика и браузерные сценарии
.github/workflows/      # сборка, тесты и GitHub Pages
```

Ключи localStorage: `tablequest.language`, `tablequest.game`, `tablequest.demo.game`, `tablequest.feedback`, `tablequest.demo.feedback`. Для удаления локальных данных очистите хранилище сайта в браузере. Сохраняются только язык, состояние игры и локальные ответы на опрос. Демо не заменяет обычную сохранённую игру или обычные отзывы.

## Деплой и QR

### GitHub Pages

1. В репозитории откройте **Settings → Pages → Source → GitHub Actions**.
2. Запустите workflow **Deploy TableQuest to GitHub Pages** во вкладке Actions или отправьте commit в `main`.
3. После успешного деплоя сайт: `https://<username>.github.io/tablequest/`.
4. Откройте сайт → меню «…» → «QR для вашего стола» → вставьте публичную ссылку (можно добавить `?table=12`) → скачайте SVG. Распечатайте и проверьте сканирование с телефона.

Workflow уже задаёт `BASE_PATH=/tablequest/`. Если измените имя репозитория, обновите путь. Локально и для домена в корне base по умолчанию `/`.

### Netlify или Vercel

Импортируйте GitHub-репозиторий. Команда сборки: `npm run build`; каталог результата: `dist`; Node.js 24. Переменную `BASE_PATH` не задавайте для корневого домена. После деплоя используйте выданную HTTPS-ссылку для QR. Приложение использует состояние без дополнительных URL-маршрутов, поэтому SPA rewrite для текущей версии не нужен.

Загружайте на статический хостинг содержимое `dist/`, а не исходники. Service worker включён только в production-сборке. Предложение обновить уже открытый клиент находится во вторичном меню; обновление не прерывает раунд.
